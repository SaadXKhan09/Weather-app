#  Weather App

A simple weather application that shows real-time weather data for any city.

##  Features
- Search weather by city name
- Displays temperature, humidity, and conditions
- Responsive UI
- Real-time data using API

##  Tech Stack
- React (Vite)
- JavaScript
- CSS
- Weather API

##  Installation

1. Clone the repo:
   git clone https://github.com/SaadXKhan09/Weather-app

2. Install dependencies:
   npm install

3. Run the app:
   npm run dev
